# BLACK-JACK-game-
I built this simple Blackjack game in Python to practice logic flow. It’s played right in the terminal and features a dealer AI that hits until 17, automatic Ace-value adjustment (11 to 1) so you don't bust, and some cool ASCII art. It's clean, fun, and easy to run. Feel free to check out the code and play a few rounds! 🃏✨
